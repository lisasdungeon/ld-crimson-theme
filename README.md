# LD Crimson Theme

LD Crimson Theme is a standalone Foundry VTT theme module that applies a dark crimson visual treatment across the interface, adds themed control art, and optionally applies random background artwork to resizable windows.

## Features

- Crimson-styled application frames, controls, chat, and pause banner
- Optional rotating themed window backgrounds
- Themed interface sound effects for buttons and window open or close actions
- Standalone Foundry v13 support

## Installation

Install the module from this manifest URL:

`https://github.com/ld-crimson-blood/ld-crimson-theme/releases/latest/download/module.json`

## Setting

- **Enable Random Backgrounds**: Applies rotating themed artwork to resizable windows

## Compatibility

- **Foundry VTT**: v13+ (verified v14)
- **Systems**: system agnostic
